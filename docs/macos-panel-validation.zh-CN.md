## 支持边界

本轮实现的是可运行的开发版，不代表 Wallpaper Engine 全格式、全脚本语义或逐像素一致性。
库中没有真实 Web 项目，网页验证使用 `macos/Tests/Fixtures/web`，没有创意工坊 Web 兼容矩阵。
视频循环由 AVPlayerLooper 管理；本轮仅对播放时间和暂停状态进行检查，没有逐帧测量每个长视频的循环边界。
仅实际连接了内置显示器，未声称多屏热插拔和不同缩放比例完成硬件验收。

系统音频频谱、媒体信息、桌面专属点击路由、自动前台应用/电池播放策略尚未接入。
Linux 的 GPU 选择、应用规则及不生效的设置在 macOS 面板隐藏；跨屏复制渲染不提供。
Web 音量通过原 bridge 通知并更新 HTML 媒体，任意自定义 WebAudio 混音仍取决于页面实现。
CEF 当前使用开发配置、关闭 Chromium 沙箱；应用依赖本机 Python/Homebrew/DXC/MoltenVK，发行包、公证与沙箱仍待完成。
